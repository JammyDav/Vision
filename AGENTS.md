# Project guidance

- Keep the GitHub Pages frontend buildless, modular JavaScript in public/src/.
- Never put provider keys, access tokens, frames, or personal diagnostic reports in Git.
- Never infer passthrough pixel access from immersive-ar support, a granted permission, a camera label, or a successful track alone.
- Preserve explicit camera selection. Do not silently replace the strict environment request with an avatar or other input.
- Keep AI upload user initiated, single frame, reviewed and consented. No background streaming.
- Only public/ may be copied to the Pages artifact. Keep server/ separate.
- Run npm run check, npm test, and npm run build before committing.
- Headset verification is manual; do not describe mocked webcam tests as Quest hardware validation.
